# Example files

Each file uses placeholders. Replace `<your-host>`, `<your-port>` and `<your-https-address>` with the values the [feed page](https://gangwayais.com/stations/feed-us/) gives your station.

| Folder | For |
|---|---|
| [ais-catcher](ais-catcher/) | AIS-catcher on the command line, as a service and over HTTPS |
| [docker-shipfeeder](docker-shipfeeder/) | docker-shipfeeder with your own port |
| [kplex](kplex/) | dAISy, rtl-ais and a Class B transponder through kplex |
| [rtl-ais](rtl-ais/) | rtl-ais as a service |
| [opencpn](opencpn/) | OpenCPN as a forwarder |
